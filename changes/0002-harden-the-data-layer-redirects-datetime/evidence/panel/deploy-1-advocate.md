The record the owner will actually read is weak. `evidence/claude-md-proposals.md` reproduces the finding under "Things Claude gets wrong", a diagnosis, not the edit; CLAUDE.md already holds the 0001 bullet for this pattern, so a second bullet teaches nothing.
